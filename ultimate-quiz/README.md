# 얼티미트 규칙 퀴즈 — 설정 안내

학생: 학번 5자리 + 이름으로 들어가서 10문항을 풀어요. 응시는 1번만 할 수 있고, 7문항 이상 맞히면 통과예요.
교사: 화면 아래 **교사 모드**에서 비밀번호 5자리로 들어가 결과를 보고 엑셀로 내려받아요.

파일
- `index.html` — 퀴즈 앱 전체 (GitHub에 올리는 파일)
- `firestore.rules` — Firebase 보안 규칙 (Firebase 콘솔에 붙여 넣는 내용)

---

## 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com → **프로젝트 추가** (예: `ultimate-quiz`)
2. 프로젝트 홈에서 **웹 앱 추가(</>)** → 앱 이름 입력 → 등록
3. 화면에 나오는 `firebaseConfig = { ... }` 값을 복사해서
   `index.html` 위쪽 **① Firebase 설정** 부분에 그대로 붙여 넣기

## 2. Firestore 데이터베이스 만들기
1. 왼쪽 메뉴 **빌드 → Firestore Database → 데이터베이스 만들기**
2. 위치: `asia-northeast3 (서울)` 추천 → **프로덕션 모드**로 시작
3. **규칙** 탭 → 내용을 모두 지우고 `firestore.rules` 내용을 붙여 넣기 → **게시**

## 3. 교사 계정 만들기 (비밀번호 5자리)
1. **빌드 → Authentication → 시작하기 → 이메일/비밀번호** 사용 설정
2. **Users → 사용자 추가**
   - 이메일: `teacher@ultimate-quiz.app` (실제 메일이 아니어도 됨)
   - 비밀번호: **원하는 5자리 숫자 + quiz** (예: `12345quiz`)
     → Firebase 비밀번호는 6자 이상이어야 해서 뒤에 `quiz`를 붙여요.
       교사 모드에서는 **앞의 5자리(12345)만** 입력하면 돼요.
3. 이메일을 바꾸고 싶으면 `index.html`의 `TEACHER_EMAIL`과 `firestore.rules`의 이메일을 **둘 다** 똑같이 바꾸세요.

## 4. GitHub Pages로 올리기
1. GitHub에서 새 저장소 만들기 (예: `ultimate-quiz`, Public)
2. **Add file → Upload files** → `index.html` 업로드 → Commit
3. **Settings → Pages** → Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save
4. 1~2분 뒤 `https://내아이디.github.io/ultimate-quiz/` 주소로 접속 (이 주소를 QR코드로 만들어 학생들에게 공유)

## 5. 사용 전 확인
- 테스트 학번(예: `99999`)으로 한 번 풀어 보고, 교사 모드에서 결과가 보이는지 확인
- 확인 후 교사 모드에서 테스트 기록의 **재응시 허용**을 눌러 지우기

---

## 사용법
**학생**
- 학번은 5자리 숫자 (예: 1학년 7반 12번 → `10712`)
- **시작!**을 누르는 순간 응시 기록이 남아요. 같은 기기에서 새로고침하면 이어서 풀 수 있어요.
- 문제 순서와 보기 순서는 학생마다 섞여서 나와요.
- 결과 화면에는 점수와 통과 여부만 나오고 정답은 나오지 않아요.

**교사**
- 반별·결과별(통과/미통과/미제출)로 골라 볼 수 있어요.
- **문항별 정답률**로 어떤 규칙을 학생들이 헷갈려 하는지 볼 수 있어요.
- **엑셀 다운로드**: 지금 고른 반·결과만 내려받아요. 시트 2개(결과 + 문항별 O/X, 문항별 정답률)
- **재응시 허용**: 그 학생의 기록을 지워서 다시 응시할 수 있게 해요. (도중에 기기가 꺼진 학생 등)

## 바꾸고 싶을 때
- 통과 기준: `index.html`의 `PASS_SCORE`
- 문항: `index.html`의 `QUESTIONS` (`answer`는 정답 보기 번호이고 **0부터** 세요. 첫 번째 보기 = 0)
- 문항 수를 바꿔도 규칙 파일은 그대로 써도 돼요.

## 알아 두면 좋은 점
- 결과는 교사 계정으로만 읽을 수 있고, 학생은 한 번 제출한 결과를 고칠 수 없어요.
- 정답과 채점은 학생 기기(브라우저)에서 처리해요. 개발자 도구를 다룰 줄 아는 학생이라면 정답을 볼 수 있으니, 성적에 크게 반영하는 시험보다는 수업 확인용 퀴즈로 쓰는 게 알맞아요.
- 남의 학번으로 먼저 응시하면 그 학번은 막혀요. 이런 일이 생기면 교사 모드에서 이름을 확인하고 **재응시 허용**을 누르세요.
